Organization
============

An organization is the fundamental data entity representing a company, sole proprietor, project, or individual. It contains all managed data and defines access permissions.

## Organization Types

BizKitHub supports various organization types based on your needs and business characteristics.

### Company

Commercial enterprise with multiple employees and projects. Examples: LLC, Corp, Inc.

### Sole Proprietor

Individual conducting business under a trade license. Examples: self-employed, freelancer, consultant.

### Project

Temporary or long-term project-based grouping. Examples: startup, research project, open source.

### Individual

Personal user account for individual purposes. Examples: personal projects, portfolio, testing.

## Organization Creation Process

Creating an organization is quick and easy. Just four steps.

### 1. Complete Registration Form

Creating an organization starts with filling in basic information about your company, project, or group.

### 2. Assign Organization Administrator

The person who creates the organization automatically becomes its administrator with full privileges.

### 3. Define Organization Members

Assign permissions to existing users or register new accounts for team members.

### 4. Configure API Access

The organization gains the right to issue API keys for communication with external applications.

## Organization Membership

A flexible membership system enables efficient team and data access management.

- One user can be a member of multiple organizations simultaneously.
- Each user can create new organizations.
- Assign permissions to existing user accounts.
- Register new accounts for organization members.
- Hierarchical roles and permissions.

## API Key Issuance

Each organization has the right to issue API keys for communication with the frontend and external applications. API keys enable secure access to organization data.

### Security

API keys are generated with a high level of security and can be deactivated at any time.

### Monitoring

All API calls are logged and monitored to ensure security.

### Flexibility

Ability to create multiple keys with different permissions and restrictions.

### Integration

Easy connection with your applications and external systems.

See the [API key documentation](/api-key-overview) for more details.
