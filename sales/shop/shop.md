Shop
====

The `/shop` page is reserved for central e-shop settings — meaning for parameters that influence the behavior of the sales process across all modules (Products, Orders, Payments, Shipping). The goal of the module is to centralize values that need to be set consistently — currencies and exchange rates, default VAT rates, rounding rules, or conditions for cancellation and refunds.
> ⚠️ **The module is under development.** Currently, a placeholder "Shop page work in progress" is displayed in the administration, and specific functionality is not available. Documentation will be added after the module's deployment.
## What the module is for
Instead of setting general e-shop parameters in each module separately (where you might easily overlook them or misconfigure them), the `/shop` module provides one clear location for shared values. This includes, for example, a list of supported currencies including exchange rates and rounding rules, default VAT rates for both products and shipping, general rules for combining shipping methods and payment methods, the minimum order value applicable across order groups, settings for cancellations and refunds, and also default email templates for notifications. The goal is for the e-shop operator to have a single view of the overall sales process configuration and be able to manage it without having to jump between dozens of sub-pages.
