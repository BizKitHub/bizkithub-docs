Configuration
=============

The `/configuration` page is reserved for advanced organization configuration that goes beyond the scope of standard settings available in the `/settings` and `/organisation` modules.

> ⚠️ **The module is under development.** Currently, the page displays a placeholder "Shop page work in progress" and no functionality is publicly available.

## What will be added here eventually

The module's intention is to provide a unified space for settings that are advanced or experimental in nature and do not make sense in a typical overview. The specific scope will be added upon deployment.

## Where to find settings in the meantime

Until the module is completed, manage configuration in the existing sections:

- **Everyday organization profile, branding, emails, subscription plan, data import** — see [`/organisation`](/organisation-overview)
- **API keys, domains, routes, environment variables, terminal, IP blocking** — see [`/settings`](/settings-overview)
- **System administration of organizations and users** — see [`/admin`](/admin-panel)

> ℹ️ The documentation for this page will be expanded once the module is deployed to production.
